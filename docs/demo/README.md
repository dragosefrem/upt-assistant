# Demo interactiv UPT Orar

`index.html` e o pagină de sine stătătoare care arată interfața aplicației, cu un orar și
examene de exemplu. Nu are nevoie de server sau de bază de date: o deschizi direct în browser.

Versiunea publicată: https://claude.ai/artifact/1rzWqtq5c7nfpsQg1vaN89

Ce poți încerca:

- **Calendar:** clic pe o oră liberă sau tragi cu mouse-ul ca să adaugi un eveniment;
  în vederea pe lună, butonul `+` de pe fiecare zi.
- **Poli:** apasă pe orice Poli ca să deschizi chatul (sare și scoate inimioare).
  Butoanele rapide din cardul de salut întreabă direct.
- **Exams:** examenele cu sala, clădirea, harta și sfaturile lui Poli, plus căutarea.
- **🔔 Clopoțelul:** remindere pentru examene cu sala la care trebuie să ajungi.

Evenimentele adăugate rămân doar în browserul tău (localStorage). Răspunsurile lui Poli
sunt pregătite dinainte; în aplicație, asistentul folosește datele reale.
